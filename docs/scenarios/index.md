# Scénarios prêts à jouer

Sept scénarios, un par quartier, chacun jouable en une séance de deux
à trois heures. Chacun développe la première trame de son quartier
en scènes, avec oppositions chiffrées et prétirés. Ils se jouent
seuls ou à la suite.

Les deux scénarios d'initiation apprennent le jeu en jouant : le
premier fait découvrir les dés, les aspects et les complications, le
second les Serments, un premier conflit et la concession. Ils sont
écrits pour le premier jeu de [prétirés](../jouer/pretires.md) ; les
cinq autres scénarios conseillent le second.

Chaque kit est un seul PDF A4 : le livret du meneur, une page pour
les joueurs, les fiches des prétirés, les cartes citées dans les
scènes et les cartes de sécurité.

> [!MJ] Des scénarios pas encore testés
> Le minutage des scènes, les difficultés et les profils des PNJ sont
> indicatifs : aucun des sept n'a été testé en partie.
