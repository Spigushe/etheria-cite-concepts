# La Citadelle de l'Arété, aventures

Cinq aventures qui testent moins des actes que des dispositions
durables. Eudémos et Alea d'Ilion réapparaissent souvent, jamais pour
juger directement, toujours pour révéler ce que le choix révèle du
caractère.

## Éléments de jeu

- Concept sous-jacent : l'éthique de la vertu comme disposition acquise par l'habitude, chez Aristote, prolongée par Thomas d'Aquin et MacIntyre, avec en écho la tradition confucéenne.
- PNJ clés : Eudémos (n'enseigne que par l'exemple), Alea d'Ilion (ancienne voyageuse des sept quartiers, revenue enseigner la constance), la Sentinelle Blanche (ne parle que lorsqu'une vertu est niée trois fois).
- Entrer exige de reconnaître une faiblesse morale en soi ; le Col de l'Incomplétude est un sentier raide où chaque pas demande une lucidité nouvelle.
- Dilemmes types : agir courageusement quand on sait l'action inutile, cacher une vérité pour préserver l'estime d'un proche, rester fidèle à ses principes dans un monde qui les bafoue.
- Connexions : affinité avec les Jardins de l'Équité et la Concorde du Pacte ; méfiance envers la Balance d'Orion (sacrifice de la vertu à l'efficacité) et le Labyrinthe des Identités (jugé trop instable pour un soi stable) ; tension avec le Gouffre d'Absyr (la vertu a-t-elle un sens dans un monde sans signification donnée) et avec les Rails de la Décision (bien décider suppose d'être déjà vertueux, alors que la vertu se construit lentement).
- Mythe exploitable : la Pierre Non Jetée (colère enterrée, retrouvée fendue en deux, cent ans plus tard, symbole du pardon silencieux), le Chemin des Semblants (où l'on peut imiter toutes les vertus sans les vivre).

Le concept, ses philosophes et les questions à poser à la table sont
dans la [fiche concept](concepts/citadelle-de-l-arete.md). Le décor, les habitants et
les menaces sont dans la [fiche du quartier](../cite/quartiers/citadelle-de-l-arete.md).

## Le Jardin des Épreuves

| | |
| - | - |
| Accroche | Pour intégrer la Citadelle, les Aventuriers doivent traverser un jardin rempli d'épreuves symboliques, chacune conçue pour éprouver une vertu précise : courage, tempérance, justice, prudence. |
| Scènes clés | Chaque épreuve met en scène une situation concrète où tricher serait facile et probablement indétectable, un adversaire truqué à affronter, une tentation de raccourci, un besoin réel de patience face à une attente sans fin apparente. |
| Bascule | Lors de l'épreuve de justice, un Aventurier réalise qu'il peut sauver un camarade en trichant discrètement, ou échouer honnêtement en respectant la règle du jeu. |
| Dénouements possibles | Tricher pour sauver le camarade et réussir l'épreuve par un moyen détourné, échouer honnêtement et recommencer plus tard, ou révéler publiquement la tentation de tricher, quitte à ralentir tout le groupe. |
| Portée | La vertu est une disposition stable, pas une action ponctuelle : elle s'éprouve dans la constance face à la tentation, pas dans un seul geste isolé. |
| Type de dilemme | Contradiction interne |
| Thèmes sensibles | Aucun |

## L'Ombre du Sage

| | |
| - | - |
| Accroche | Le guide reconnu à la Salle de l'Exemplarité a disparu sans laisser d'explication, et ses disciples se sont divisés en factions rivales, chacune revendiquant une vertu comme supérieure aux autres : la force, la justice, la sagesse. |
| Scènes clés | Les Aventuriers rencontrent chaque faction, écoutent leurs arguments, souvent cohérents pris isolément, et découvrent que leurs conflits paralysent désormais l'enseignement même de la Citadelle. |
| Bascule | Restaurer l'harmonie semble exiger d'écarter l'une des factions, qui incarne pourtant une vertu authentique, simplement moins compatible avec les autres dans son expression actuelle. |
| Dénouements possibles | Écarter la faction la plus intransigeante au nom de l'unité, tenter une synthèse fragile entre toutes les factions, ou renoncer à unifier l'enseignement et laisser coexister plusieurs écoles rivales. |
| Portée | La vertu comme juste milieu, chère à Aristote, suppose un équilibre entre plusieurs qualités plutôt qu'un excès dans une seule direction, fût-elle louable. |
| Type de dilemme | Cas collectif |
| Thèmes sensibles | Aucun |

## Le Miroir d'Éleusis

| | |
| - | - |
| Accroche | Un artefact légendaire, le Miroir d'Éleusis, révèle la véritable nature morale de quiconque s'y regarde. La Citadelle demande aux Aventuriers de l'utiliser pour identifier un traître infiltré parmi ses rangs. |
| Scènes clés | Le miroir livre des verdicts troublants : certains membres réputés vertueux y apparaissent ambigus, tandis qu'un personnage au comportement irréprochable depuis des années y est jugé indigne de confiance. |
| Bascule | Le comportement observable de cette personne reste exemplaire en tout point, mais le miroir insiste sur son indignité intérieure, sans qu'aucune preuve extérieure ne vienne l'appuyer. |
| Dénouements possibles | Faire confiance au miroir et écarter la personne jugée indigne, ignorer le verdict et se fier uniquement aux actes observés, ou chercher à comprendre ce que le miroir perçoit réellement avant de trancher. |
| Portée | La vertu n'est pas qu'apparence mais habitude intérieure, et pourtant la vérité morale d'autrui ne devrait peut-être jamais s'imposer de l'extérieur sans discussion. |
| Type de dilemme | Sphinx moral |
| Thèmes sensibles | Accusation sans preuve |

## Le Feu de la Sophrosynê

| | |
| - | - |
| Accroche | Un feu mystique, réputé ne consumer que les excès, se propage lentement dans la Citadelle. Les Aventuriers doivent choisir quelles zones sacrifier pour sauver l'ensemble de l'édifice. |
| Scènes clés | Le feu épargne les lieux de mesure et de tempérance, mais menace directement la bibliothèque des vertus héroïques, dédiée au courage extrême, et le sanctuaire de la compassion, dédié au don de soi sans limite. |
| Bascule | Les deux lieux menacés incarnent chacun une vertu authentique, mais poussée à un excès que le feu semble juger dangereux ; aucun ne peut être sauvé sans sacrifier l'autre. |
| Dénouements possibles | Sauver la bibliothèque du courage au prix du sanctuaire de la compassion, l'inverse, ou tenter une action risquée pour sauver les deux, au péril direct des Aventuriers. |
| Portée | La tempérance, sophrosynê, reste le centre de gravité des vertus : toute qualité, même noble, peut devenir un vice si elle échappe à toute mesure. |
| Type de dilemme | Tramway moral |
| Thèmes sensibles | Aucun |

## Le Parchemin Inachevé

| | |
| - | - |
| Accroche | Un ancien élève prodige, parti vivre dans le monde sans jamais valider formellement son parcours à la Citadelle, a transformé des régions entières par ses actions, sans jamais demander à être reconnu comme guide à la Salle de l'Exemplarité. |
| Scènes clés | Les Aventuriers recueillent des témoignages sur ses actes, souvent discrets, jamais spectaculaires, mais dont l'effet cumulé sur les communautés visitées est indéniable et durable. |
| Bascule | Le reconnaître comme guide à la Salle de l'Exemplarité, alors qu'il n'a jamais traversé les épreuves de la Citadelle, remettrait en question la manière dont le quartier reconnaît ses guides. |
| Dénouements possibles | Le reconnaître comme guide malgré l'absence de parcours à la Citadelle, le refuser au nom de la cohérence institutionnelle, ou proposer une nouvelle catégorie de reconnaissance, fondée uniquement sur les effets constatés. |
| Portée | La vertu est-elle un état intérieur, une reconnaissance sociale ritualisée, ou simplement l'effet durable produit sur le monde et sur autrui. |
| Type de dilemme | Cas collectif |
| Thèmes sensibles | Aucun |
